## 4. Key Endpoints for Verification

| Route | Role Access | Description |
| :--- | :--- | :--- |
| `http://localhost:8082/` | **Guest / Public** | Redesigned discovery page showing open kitchens, operating hours, real-time status, horizontal menus, and quick order actions. |
| `http://localhost:8082/login` | **All** | Sign in with any of the credentials above. |
| `http://localhost:8082/bookings/me` | **Customer** | View client booking history (filter by Confirmed, Pending, Cancelled). |
| `http://localhost:8082/vendor/bookings` | **Vendor** | Caterer dashboard with daily resource utilization (Staff, Utensils, Vehicles, Venue covers) and incoming order approvals. |
| `http://localhost:8082/vendor/cuisines` | **Vendor** | Manage culinary menus, dietary tags, price per head, and min/max guest thresholds. |
| `http://localhost:8082/vendor/resources` | **Vendor** | Configure fleet limits, servers, cutlery stock, and seated venue covers. |
| `http://localhost:8082/admin/bookings` | **Admin** | Global platform booking audit with search and status actions. |
| `http://localhost:8082/admin/users` | **Admin** | User directory with activate/deactivate account controls. |
