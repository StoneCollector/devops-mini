💡 How Automatic Resource Feasibility Works

Unlike naive slot booking, every customer booking request is checked against your daily resource pool: Staff (1 server / 15 guests + 1 captain if >30 + 1 chef / 50 guests), Utensils (1.15 sets / guest with breakage buffer), Vehicles (1 vehicle per delivery event), and Venue Space (at-venue seating limits). If any resource exhausts on the requested date, the system prevents booking conflicts.
